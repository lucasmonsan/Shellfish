# Shellfish Project Context

Shellfish is a standalone open source PC console-style game launcher/front-end.
It aims to turn a Windows or Linux gaming PC into a console-like experience:
controller-first navigation, unified game libraries, local metadata, downloads,
emulation, save backup and direct game launch without requiring keyboard/mouse
after setup.

Use this file as compact context for another AI/chat. Use `README.md` for setup
and operational commands once the project README is updated. Use workspace root
`AGENTS.md` as the canonical implementation rules. Use workspace root
`SUITE_CONTEXT.md` for the cross-project map.

## Non-Negotiable Rules

- Svelte 5 only.
- pnpm only.
- Strict ESLint, Prettier, TypeScript and Svelte checks.
- i18n for every user-facing string.
- a11y for every route and interaction, including controller navigation.
- Desktop/gamepad-first UX: every post-setup flow must be usable with a
  controller.
- Do not expose store credentials, OAuth tokens, API keys, save paths or private
  user data in logs, client code, commits or docs examples.
- Do not change local database schemas, save-management behavior or destructive
  file operations without a backup/migration plan.
- Keep the current product visual direction explicit: Shellfish targets a
  neobrutalist console UI. If it starts consuming MonsanUI, add or extend
  MonsanUI APIs instead of locally restyling shared components.

## Responsibilities

- Provide a console-like launcher for PC gaming libraries.
- Unify Steam, Epic Games, GOG, Itch.io, emulators and local executables.
- Support controller-first browsing, search, filters, details and launch flows.
- Manage installation/download flows through store APIs or CLI wrappers.
- Manage local metadata, configuration, themes, play history and save backups.
- Provide a setup wizard for stores, emulators, directories and controller
  configuration.
- Eventually support boot/direct-shell style operation for dedicated gaming PCs.

Shellfish does not currently own or depend on Owlth SSO, Examster, Manki or
Directus data. If that changes, document the contract here before implementing
the integration.

## Stack

- SvelteKit with Svelte 5.
- TypeScript.
- Paraglide i18n.
- Planned Tauri v2 desktop shell with Rust backend.
- Planned SQLite local database.
- Planned store/launcher integrations through Steam APIs/protocols, Legendary,
  gogdl, Itch.io APIs, emulator CLIs and filesystem scanning.

- The repository currently contains a SvelteKit foundation generated by `sv`.
- `package.json` has `dev`, `build`, `preview`, `check`, `lint` and `format`;

## 1. Sumário Executivo

Shellfish é um front-end "console-like" open source (AGPLv3) para PC que transforma qualquer computador em um console de videogame. Unifica todas as bibliotecas de jogos — Steam, Epic Games, GOG, Itch.io, emuladores e executáveis locais — em uma interface única, rápida e 100% navegável por controle. Roda nativamente em Windows e Linux, pode substituir o shell do sistema operacional (boot direto), e oferece instalação, gerenciamento e execução de jogos sem jamais exigir teclado ou mouse após o setup inicial.

- **Diferencial central:** Experiência de console real — sentar no sofá, ligar o PC, e jogar. Zero fricção.
- **Estética:** Neubrutalismo — cores de alto contraste, tipografia bold, sombras sólidas sem blur, bordas grossas, animações exageradas, identidade visual marcante e anti-genérica. Sistema de temas expansível pela comunidade.

## 4. Funcionalidades

### 4.1 MVP (Primeira versão estável)

#### Biblioteca de Jogos

- Grid de capas responsivo com scroll virtual (suporta 10k+ jogos a 60fps).
- **Navegação Inteligente na Grid:** O componente de scroll virtual em Svelte 5 deve prever o movimento do D-Pad/analógico, renderizando as linhas adjacentes (buffer preventivo) antes que o foco do controle atinja os limites visíveis, evitando quebras de foco ou travamentos de navegação.
- Três modos de visualização: Grid (capas), Lista (com detalhes), Banner horizontal (estilo carrossel).
- Detalhes do jogo: sinopse, screenshots (galeria expansível), trailer (YouTube), nota (Metacritic via IGDB), horas jogadas, achievements, data de lançamento, desenvolvedor, publisher, gêneros, tags.
- Indicador visual de status: instalado (✓), na nuvem (☁️), baixando (⬇ com barra de progresso), fila (⌛), erro (⚠️).

#### Pesquisa e Filtros

- Busca textual rápida com debounce (resultados em tempo real enquanto digita).
- Teclado virtual on-screen otimizado para controle (grid A-Z, navegação rápida).
- Busca interna (biblioteca local, resultados instantâneos do SQLite).
- Busca externa integrada: pesquisar em lojas (Steam, Epic, GOG, Itch.io) jogos que o usuário possui mas ainda não importou, ou jogos que não possui mas estão disponíveis.
- **Filtros:**
  - Por status: Todos / Instalados / Não instalados / Baixando
  - Por plataforma/loja: Steam / Epic / GOG / Itch.io / Emuladores / Local
  - Por emulador específico: RetroArch / Dolphin / (futuros)
  - Por gênero: Ação, Aventura, RPG, Estratégia, Esporte, Corrida, Indie, etc.
  - Por ano de lançamento (slider ou décadas)
  - Por nota (Metacritic: 90+, 80+, 70+, etc.)
  - Por tempo de jogo: 0h (nunca jogado), < 1h, 1-10h, 10-50h, 50h+
  - Por multiplayer: Local / Online / Single player
  - Filtros combináveis (AND lógico)
- **Ordenação:** Nome, Data de adição, Última sessão, Horas jogadas, Nota, Tamanho (Ascendente / Descendente).
- **Agrupamento:** Por plataforma, por gênero, por status.
- Indicador visual dos filtros ativos com contagem de resultados.
- **Favoritos:** Marcar/desmarcar jogo como favorito (⭐) e filtro rápido ⭐ Favoritos.

#### Menu Home (estilo Steam Big Picture)

Ao pressionar o botão Home/Guide/PS no controle (or tecla Home no teclado), um menu overlay desliza sobre o conteúdo atual:

- **Seções do Menu Home:**
  - 🏠 Início — Voltar para a tela principal (grid de jogos)
  - 📚 Biblioteca — Acesso rápido à grid completa
  - ⭐ Favoritos — Lista de jogos favoritados
  - ⬇ Downloads — Gerenciador de downloads ativos (fila, progresso, pausar/cancelar)
  - 💾 Gerenciador de Saves — Acesso ao histórico de backups e configurações
  - ⚙️ Configurações — Acesso às configurações do app
  - 🎨 Temas — Seleção e download de temas da comunidade
  - 🔌 Lojas — Gerenciar conexões (reconectar, adicionar nova loja)
  - 🕹️ Controles — Configuração global de gamepad (mapeamento, deadzone, vibração)
  - ℹ️ Sobre — Versão, créditos, links (GitHub, Discord, doar)
  - 🚪 Sair — Opções: Voltar ao jogo / Sair para Desktop / Desligar PC / Reiniciar PC / Suspender
- **Comportamento:**
  - Overlay com fundo semi-transparente escuro (blur + escurecer).
  - Menu desliza da esquerda ou centro com animação rápida.
  - Navegação vertical com analógico/D-Pad.
  - A = selecionar, B = fechar menu.
  - O menu aparece sobre qualquer tela (biblioteca, detalhes, configurações).
  - Estado anterior é preservado ao fechar o menu.

#### Integração com Lojas

- **Steam:** OAuth login, listar biblioteca completa, achievements, horas jogadas, cloud sync. Instalar via protocolo `steam://install` com monitoramento de progresso. Lançar jogos via `steam://run`.
- **Epic Games:** Login via Legendary, listar biblioteca completa, cloud sync. Instalar e lançar via Legendary CLI.
- **GOG:** Login via gogdl, listar biblioteca completa. Instalar e lançar via gogdl CLI.
- **Itch.io:** Login via API oficial (OAuth), listar biblioteca. Instalar e lançar via API oficial.

#### Emulação

- RetroArch integrado (núcleos configuráveis).
- Dolphin integrado (GameCube/Wii).
- Configuração global de controle unificada para todos os emuladores.
- Escaneamento de ROMs em pastas configuradas com metadados automáticos (IGDB).

#### Jogos Locais

- Adição manual de executáveis com busca automática de metadados (IGDB).
- Scraping de pasta selecionada pelo usuário (busca recursiva de `.exe` e binários).

#### Gerenciamento de Saves

- Backup local automático ao fechar jogo.
- Versionamento de backups com data/hora.
- Interface de gerenciamento: listar, restaurar, excluir, exportar backups.
- Opção de o usuário definir manualmente o diretório de save por jogo.
- Integração com Steam Cloud Sync (disparar sync nativo da Valve).
- Integração com Epic Cloud Sync (Legendary sync-saves).
- Cloud sync opcional via pastas observadas em nuvens (Google Drive, OneDrive, Dropbox, Nextcloud).
- Mapeamento automático de localizações de save via PCGamingWiki.

#### Sistema de Temas

- Tema padrão: Neubrutalismo.
- Temas definidos por arquivo de configuração (JSON/YAML) + assets (imagens, fontes).
- **Variáveis customizáveis por tema:** Paleta de cores, tipografia, border radius, intensidade de sombras, espaçamento, escala dos cards, animações, opacidade do overlay, estilo de indicadores e background.
- **Instalação de temas:**
  - Temas internos (vêm com o app): Neubrutalismo, Minimalista Dark.
  - Temas da comunidade: arquivos `.shelltheme` (zip com config + assets).
  - Instalação via GitHub Releases de temas ou pastas locais.
  - Futuro: marketplace integrado no app (navegar, instalar, avaliar).
- Seleção de tema em tempo real com preview instantâneo.
- Documentação aberta para criação de temas por terceiros.

#### Controle e Navegação

- Suporte completo a Gamepad API (XInput, DualSense, Nintendo Switch Pro).
- Navegação por grid com analógico/D-Pad.
- Botão Home/Guide/PS abre o Menu Home (overlay).
- **Atalhos consistentes em todo o app:**
  - **A** = Selecionar/Confirmar
  - **B** = Voltar/Cancelar
  - **X** = Contexto (detalhes, opções secundárias)
  - **Y** = Filtros/Pesquisa
  - **Start** = Menu Home
  - **Select** = Alternar modo de visualização (Grid/Lista/Banner)
  - **LB/RB** = Navegar entre abas/seções
  - **LT/RT** = Page Up/Page Down (scroll rápido)
- Modo Big Picture (fullscreen, elementos grandes, fonte aumentada).

#### Setup Wizard

- Detecção de lojas instaladas.
- Download e instalação silenciosa do Steam, Legendary, gogdl.
- Fluxo de autenticação OAuth guiado (uma vez por loja).
- Detecção de emuladores ou instalação assistida.
- Configuração inicial de diretórios de saves e nuvem.

#### Técnico

- Banco SQLite local (biblioteca, metadados, tokens, configurações, histórico de saves, temas).
- Empacotamento: `.msi` (Windows), `.AppImage`/`.deb` (Linux).
- Modo shell: substituir `explorer.exe` no Windows, option de boot direto.
- Restauração automática de foco após fechar jogo.

## 8. Gerenciamento de Saves (Detalhamento Técnico)

### 8.1 Fontes de Localização de Saves

- **PCGamingWiki:** Maior base colaborativa de paths de save por jogo via API/scraping gratuito.
- **Steamworks API:** Alguns jogos reportam o path do save via API (Limitado, mas oficial).
- **Legendary:** `legendary list-saves` retorna paths da Epic Games.
- **Manual do usuário:** Usuário pode definir o diretório manualmente por jogo (Sempre disponível).

### 8.2 Política de Backup

- **Jogo é fechado:** Backup automático do diretório de save.
- **Usuário solicita:** Backup manual a qualquer momento.
- **Antes de restaurar:** Backup do estado atual (snapshot de segurança).
- **Retenção:** Manter últimos 10 backups por jogo (configurável).

### 8.3 Cloud Sync

- **Steam Cloud:** Nativamente gerenciado pelo Steam. O Shellfish apenas garante que o Steam está rodando e o sync acontece. Pode-se forçar o sync via Steamworks API (`ISteamRemoteStorage`).
- **Epic Cloud:** Legendary oferece `legendary sync-saves --save-path <path>`. O Shellfish executa esse comando automaticamente após fechar o jogo.
- **Pastas de nuvem locais (Drive, OneDrive, Dropbox, Nextcloud):** O usuário seleciona uma pasta que já é sincronizada pela nuvem escolhida. O Shellfish salva os backups nessa pasta e a nuvem local cuida do upload — sem custo de infraestrutura própria. Exemplo: `C:\Users\Nome\Google Drive\Shellfish\Saves\`

## 9. Sistema de Temas (Detalhamento Técnico)

### 9.1 Arquitetura de Temas

O sistema de temas é baseado em **CSS Custom Properties** injetadas no `:root`. Cada tema é um arquivo JSON que define valores para essas variáveis. O frontend em Svelte aplica o tema trocando as propriedades no `:root` dinamicamente.

### 9.2 Instalação e Distribuição de Temas

- **Temas internos:** 2 temas inclusos no app (Neubrutalismo e Minimalista Dark).
- **Arquivo `.shelltheme`:** ZIP contendo `theme.json` + assets (fontes, preview.png). Instalável via menu.
- **GitHub da comunidade:** Repositório `shellfish-themes` onde usuários enviam temas via Pull Request.
- **Futuro:** Marketplace integrado para buscar, preview, instalar e avaliar temas diretamente do app.

### 9.3 Criação de Temas pela Comunidade

- Documentação completa: "Como criar um tema para o Shellfish".
- Guia com todas as variáveis disponíveis e exemplos visuais.
- Ferramenta de preview: carregar um `.shelltheme` e ver o resultado em tempo real sem instalar.
- Validação de schema: o app verifica se o JSON do tema é válido antes de aplicar.

## 11. Riscos e Mitigações

| Risco                                      | Probabilidade | Impacto | Mitigação                                                                                                                                                                                                                                                                                                                          |
| :----------------------------------------- | :-----------: | :-----: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Steam mudar protocolo `steam://install`    |     Baixa     |  Alto   | Fallback: abrir Steam minimizado com foco roubado e devolvido.                                                                                                                                                                                                                                                                     |
| Legendary/gogdl serem abandonados          |     Média     |  Alto   | Contribuir upstream ou forkar. Epic e GOG não quebram com frequência.                                                                                                                                                                                                                                                              |
| API do IGDB mudar ou sofrer rate limit     |     Baixa     |  Médio  | Cache agressivo no SQLite. Metadados duram meses.                                                                                                                                                                                                                                                                                  |
| Gamepad API inconsistente entre SOs        |     Média     |  Médio  | Tauri plugin + testes em ambos. DBus no Linux, XInput no Windows.                                                                                                                                                                                                                                                                  |
| Boot como shell quebrar updates do Windows |     Média     |  Alto   | Backup automático do registro. Opção "Sair para Desktop" sempre acessível. Implementar via backend backend (Rust) chamadas nativas à WinAPI (`SetForegroundWindow` e monitoramento de `HWND`) para garantir o roubo e a devolução perfeita de foco entre o front-end e os executáveis dos jogos, mesmo sem o `explorer.exe` ativo. |
| Comunidade não engajar                     |     Baixa     |  Médio  | README completo, Discord ativo, issues "good first issue".                                                                                                                                                                                                                                                                         |
| Performance com 10k+ jogos                 |     Baixa     |  Médio  | Virtual scrolling bidimensional customizado com buffer de renderização antecipada orientado ao foco do gamepad, lazy load de imagens, SQLite indexado.                                                                                                                                                                             |
| Lojas com 2FA forçando re-login            |     Média     |  Médio  | Refresh token automático. Se falhar, exibe notificação "Reconectar [loja]".                                                                                                                                                                                                                                                        |
| PCGamingWiki mudar estrutura do site       |     Média     |  Baixo  | Mapeamento comunitário fallback. Usuário define path manualmente.                                                                                                                                                                                                                                                                  |
| Backup de saves corromper arquivos         |     Baixa     |  Alto   | Verificação de integridade (hash). Snapshot antes de qualquer restauração.                                                                                                                                                                                                                                                         |
| Temas maliciosos                           |     Baixa     |  Alto   | Validação estrita do JSON via Rust backend antes da injeção. Somente variáveis CSS puras permitidas (Sem JS).                                                                                                                                                                                                                      |
| Busca externa lenta (APIs de lojas)        |     Média     |  Baixo  | Timeout de 5s, cache de resultados por 24h, indicador de loading.                                                                                                                                                                                                                                                                  |
